# Service Support Hub
1. `npm install`
2. `npm run build`  -> creates the fully static site in `out/` (pages, sitemap.xml, robots.txt)
3. Upload everything inside `out/` to your hosting (public_html). Preview locally: `npm run start`.
Booking form keys: `NEXT_PUBLIC_WEB3FORMS_KEY`, `NEXT_PUBLIC_SHEET_SCRIPT_URL` (defaults are already set in src/data/bookingData.ts).
